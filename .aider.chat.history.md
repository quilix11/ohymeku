## Критичне

**1. API-ключ Gemini живе в клієнті**
`lib/services/ai_service.dart`:

## Серйозне

**3. `_restart` скидає персонажа на офіцера**
```dart
_state = loseLife ? _state.reset() : const GameState();
```
`const GameState()` має `character = GameCharacter.officer` за замовчуванням. Якщо грали за HR — після «Play Again» отримаєте офіцера. Має бути `GameState(character: _state.character)`.

**4. TTS повністю ігнорує налаштування**
У `SettingsService` є `ttsSpeed`, `ttsVoice`, `ttsEnabled`, але `TtsService` хардкодить:
```dart
await _tts.setSpeechRate(0.55);
```
Перемикачі в UI ні на що не впливають. Або підключити, або прибрати з UI, щоб не брехати користувачу.

**5. Дві паралельні системи життів**

```dart
    color: bg,  // AppColors.background = 0xFFF3F7FA, світло-сірий
    border: Border(bottom: BorderSide(color: borderColor, width: 1.5)),
  ),
```
Тобто всередині зеленого хедера зʼявляється сіра панель із рамкою. Схоже на помилку — перевір на пристрої.

**10. `_restart` скидає персонажа на офіцера**
`lib/screens/game_screen.dart`:
```dart
_state = loseLife ? _state.reset() : const GameState();
```
`const GameState()` має `character = GameCharacter.officer`. Якщо грали за HR — після «Play Again» отримаєте офіцера.

**11. TTS ігнорує налаштування**
`lib/services/tts_service.dart` хардкодить `setSpeechRate(0.55)`, `setLanguage('en-US')` і сам обирає голос. `ttsSpeed`, `ttsVoice`, `ttsEnabled` з `SettingsService` не використовуються. До того ж:
```dart
(v['name'] as String?)?.toLowerCase().contains('en-us') == true
```
`en-us` — це локаль, а не стать. Умова майже завжди істинна, тож «male voice» обирається випадково.

**12. `speech_service` не повідомляє про авто-зупинку**
```dart
onStatus: (status) {},
```
порожній, а `onStatusChange(true)` викликається лише раз після старту. Коли мікрофон сам зупиняється через `pauseFor: 3 секунди`, `onStatusChange(false)` **не викликається**. У `GameScreen` `_isListening` лишається `true` назавжди — кнопка мікрофона «залипає».

**13. Стрік ніколи не оновлюється**
`lib/services/progress_service.dart` читає `streakDays` і `lastPlayDate`, але **жодного запису** немає. `addXp`, `deductHeart`, `addHeart` їх не чіпають. `DuoAppBar` завжди показує `0`.

**14. `deductHeart` не блокує гру при нулі сердець**
```dart
if (_profile.hearts > 0) { ... }
```
При `hearts == 0` метод просто нічого не робить, але гра **не блокується**. Немає ні перевірки «game over», ні екрана «немає сердець».

## Середнє

**15. `pubspec.yaml` — `.env` як asset**
```yaml
assets:
  - .env
```
Це і є механізм, через який `GEMINI_API_KEY` потрапляє в бандл. Підтверджує проблему безпеки з попереднього огляду.

**16. `pubspec.yaml` — зайві залежності**
`json_annotation`, `json_serializable`, `build_runner` оголошені, але жодного `.g.dart` у проєкті немає. Моделі парсяться вручну. Або прибрати, або почати використовувати.

**17. `pubspec.yaml` — `assets/sounds/` не існує**
Оголошено, але в репо немає жодного звукового файлу. Flutter видасть попередження при збірці.

**18. `duo_app_bar.dart` — невикористаний параметр**
```dart
class _StatItem extends StatelessWidget {
  final Color color;   // <-- ніде не читається
  final Color textColor;
```
`color` передається, але не використовується. Або прибрати, або застосувати.

**19. `profile_screen.dart` — колір на емодзі не працює**
```dart
Text(icon, style: TextStyle(fontSize: 24, color: iconColor)),
```
`color` на емодзі — no-op. Емодзі малюються власними кольорами. Параметр `iconColor` фактично мертвий.

**20. `character_selection_screen.dart` — зірки захардкоджені**
І в `_MainBossCard`, і в `_BossListItem` — завжди 3 золоті + 2/1 сірі. Не залежать від прогресу.

**21. `character_selection_screen.dart` — здоровʼя боса завжди 100%**
```dart
const Text('100%', ...),
```
Статичне. Не залежить від жодного стану.

**22. `settings_screen.dart` — рядки акаунта виглядають клікабельними, але не клікабельні**
```dart
const Icon(Icons.arrow_forward_ios_rounded, ...),
```
Стрілка є, `onTap` немає.

**23. `chat_bubble.dart` — іконка гучномовця не клікабельна**
```dart
child: const Icon(Icons.volume_up_rounded, ...),
```
Виглядає як «повторити озвучку», але це декор.

**24. `chat_bubble.dart` — анімація `isNew` грає назад**
```dart
.animate(target: isNew ? 1 : 0).fadeIn().slideY(begin: 0.1),
```
Коли приходить нове повідомлення, попереднє втрачає `isNew` і **анімується назад** (fade-out). Може виглядати як мерехтіння.

**25. `input_panel.dart` — `speechAvailable` не використовується**
Поле є, але в `build` не читається. Іконка мікрофона показується завжди, навіть якщо розпізнавання недоступне.

**26. `input_panel.dart` — `didUpdateWidget` затирає ручний ввід**
```dart
if (widget.isListening) {
  _controller.text = widget.liveTranscript;
```
Якщо користувач почне друкувати під час прослуховування — текст затирається транскриптом.

**27. `game_screen.dart` — повідомлення гравця дублюється в контексті AI**
```dart
final updatedMessages = [..._state.messages, playerMsg];
...
chatHistory: _state.messages,   // вже містить playerMsg
playerMessage: text.trim(),     // і ще раз окремо
```
А в `ai_service.dart` промпт склеює обидва:
```
Previous conversation:
... PLAYER: <останнє повідомлення>
Player's latest message: "<те саме>"
```
Модель бачить репліку двічі.

**28. `game_screen.dart` — `_EndDialog.livesLeft` не використовується**
Параметр передається, але в `build` не читається.

**29. `game_screen.dart` — не слухає `SettingsService`**
`widget.settings.isDark` читається в `build`, але підписки немає. Зміна теми не оновить екран, поки щось інше не викличе `setState`.

**30. `game_screen.dart` — магічне число `top: 150`**
```dart
Positioned(top: 150, ...)
```
Висота хедера захардкоджена. Будь-яка зміна шрифту/паддінгів — і чат поїде.
