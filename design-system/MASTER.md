# Ohymeku — повна перекомпоновка

## Візуальна мова

Мобільний навчальний інтерфейс із чіткими блоками, компактною ієрархією
та виразними елементами керування. Правила UI/UX Pro Max з прикріпленої
інструкції застосовані до Flutter: семантичні кольори, SafeArea, TextScaler,
доступні назви, видимі selected/disabled стани та Material feedback.

- Світла тема: тло #F8FAF5, білі картки #FFFFFF, текст #283127 / #56604F.
- Нейтральний sage #EEF1E8 для навчальних блоків, профілю й допоміжних дій.
- Matcha #838F58; кнопки використовують темніший #526137 із білим текстом.
- Темна тема: тло #191F19, поверхня #252D25, акцент #BFCC9A.
- Manrope 400–800 для інтерфейсу й заголовків. Lora для слова на картці.
- Локальний Noto Sans для IPA. [Джерело шрифту](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf), [OFL](https://github.com/notofonts/noto-fonts/blob/main/LICENSE).
  Ліцензія збережена в assets/fonts/NotoSans-OFL.txt.

Meku використовує окремий прозорий assets/images/meku_cutout.png — повний
силует через BoxFit.contain, без обрізання аркуша поз і без білого фону.
Темна палітра збережена. Знімок стану теми, анімацій, масштабу й placement
ініціалізується в initState до реєстрації слухача: перше перемикання теми
оновлює весь застосунок із увімкненими та вимкненими анімаціями.

## Усі основні типи кнопок

| Тип | Оформлення |
|---|---|
| Основна дія | Матча, радіус 12, висота від 56, рамка 2, виразна іконка, легка тінь |
| Другорядна дія | Світла поверхня, рамка 2, радіус 12, текст та іконка |
| Допоміжна дія | Тональна прямокутна кнопка, радіус 10, від 48 px |
| Кнопка-іконка | Квадрат від 48×48, радіус 12, рамка 1.5 |
| Фільтр / інтерес | Прямокутний чип із радіусом 10 та виразною рамкою |
| Відповідь у вправі | Картка-кнопка з літерою, рамкою 2, selected/correct/incorrect станами |
| Дія в списку | Іконка в окремому блоці, назва та опис, стрілка праворуч |
| Нижня вкладка | Чотири прямокутні вкладки; активна залита матча, з білими іконкою й підписом |

Усі інтерактивні компоненти використовують натискання Material без зсуву
сусіднього контенту. Disabled-кнопки використовують нативний disabled стан.
Нові компоненти розташовані в lib/widgets/ohymeku_design.dart;
теми кнопок, чипів і полів — у lib/theme/app_theme.dart.

## Компонування

| Екран | Структура |
|---|---|
| Головна | Шапка з Meku → огляд рівня/серії/XP → компактний вибір ситуації → блок вибраної розмови зі стартом → два рядки офлайн-практики |
| Словник | Заголовок і додавання → кнопка пошуку → фільтри → черга, undo та shuffle → світла картка EN/UA із вимовою → кнопки «Ще вчу» / «Знаю» → створення набору |
| Граматика | Вступ → лічильник і прогрес → блок контексту/питання → відповіді з літерами → пояснення → наступна дія |
| Вступний тест | Коротка вступна картка зі стартом → інтереси; у тесті: прогрес, питання, відповіді, «Далі» та пропуск; результат у власному блоці |
| Прогрес | Заголовок → великий блок XP → тижневі відмітки й серія → статистика практики → історія розмов |
| Профіль | Компактна картка особи з редагуванням праворуч → рівень та інтереси → три кнопки швидкого доступу → список досягнень |
| Налаштування | Поточний стан → розгорнутий «Вигляд» із вибором теми → окремі блоки навчання, інтересів, голосу й мікрофона |
| Генерація | Три секції: тема, складність, перегляд/збереження; параметри в картках, явні кнопки створення й збереження |
| Розмова | Компактна сцена → прокручувані показники й історія → поле на всю ширину → окремий ряд голосу, підказки та надсилання |
| Meku | Шапка помічниці → вертикальні кнопки запитів → повідомлення та квитанції дій → поле → широка кнопка надсилання |

## Адаптація та перевірка

Вкладки зберігаються у lazy IndexedStack. Ширина контенту обмежена на
планшетах. При збільшенні тексту вибір ситуацій стає вертикальним;
підписи вкладок замінюються доступними назвами. У чаті при великому тексті
сцена прокручується з історією, а кнопка голосу стає квадратною.

Перевірки охоплюють меню, вибір персонажа, редагування профілю, відповіді
в практиці, надсилання Meku й виконання дії, ігровий чат, клавіатуру,
320×568 / 375×812 / landscape / планшет, темну тему, текст 200% та 320%,
reduced motion. Прев’ю зберігаються в build/previews. Нативні голоси та
дозволи потребують перевірки на пристроях Android/iOS.
